# 🚦 AI Smart Traffic Controller

An AI-powered smart traffic management system that uses **YOLO11, OpenCV, and vehicle tracking** to detect vehicles from traffic video and support intelligent traffic signal management.

## ✨ Features

- 🚗 Real-time vehicle detection
- 🎯 YOLO11-based object detection
- 🚌 Detection of cars, motorcycles, buses and trucks
- 📹 Traffic video processing using OpenCV
- 🆔 Vehicle tracking with unique IDs
- 🚦 Smart traffic signal control concept
- 📊 Vehicle counting and traffic analysis
- 🔄 Supports traffic movement analysis
- 🖥️ Python-based application

## 🛠️ Technologies Used

- Python
- OpenCV
- YOLO11
- Ultralytics
- NumPy
- Vehicle Tracking
- Computer Vision
